# 公司X光守护（Company X-Ray Guardian）

## 项目简介

**公司X光守护**是一款运行在 Android 设备上的反诈防骗守护应用。它通过**无障碍服务**实时监测用户在各类 App 中的支付、转账、投资等操作界面，利用内置的商家数据库和风险规则引擎，对当前操作的商家进行风险等级评估，并通过悬浮窗、通知等方式及时提醒用户，同时支持将告警信息同步给绑定的家人，为中老年人及风险防范意识较弱的用户提供一道额外的安全防线。

本应用的核心定位是「**守护**」而非「**拦截**」——它不能替用户做决定，但能在用户即将向高风险商家付款时，用最醒目的方式提醒用户三思而后行。

---

## 核心功能

### 1. 无障碍监测
- 通过 Android 无障碍服务（AccessibilityService）实时读取当前屏幕的文本内容
- 自动识别支付页面、转账页面、投资页面等高危场景
- 提取商家名称、交易金额等关键字段
- 全程在本机运行，不截屏、不上传原始屏幕内容

### 2. 六锚点核验
- 对提取到的商家名称进行多维度核验：
  - **品牌库匹配**：是否在已知正规品牌库中
  - **名称相似度**：是否与知名品牌高度相似（山寨/蹭名）
  - **投资关键词**：是否包含「投资」「理财」「返利」等高风险词
  - **金额异常**：单笔金额是否超过安全阈值
  - **场景类型**：当前处于支付/转账/投资哪种场景
  - **历史记录**：该商家是否有过告警历史
- 综合六个锚点的结果，给出最终风险等级

### 3. 悬浮窗提醒
- **红色高危**：全屏红色悬浮窗 + 强振动，强制用户确认
- **黄色关注**：顶部黄色悬浮条提示，用户可自行判断
- **绿色正常**：无干扰，正常使用
- 悬浮窗始终显示在最上层，确保用户在点击「确认支付」前能看到风险提示

### 4. 家人通知
- 支持绑定最多 3 位家人（子女/配偶等）
- 高危告警时自动将告警信息（商家名称、金额、时间）推送给家人
- 家人可通过配套管理端查看告警历史
- 用户可随时解绑或关闭家人通知

## 支持的系统版本

- **最低版本**：Android 7.0（API Level 24）
- **目标版本**：Android 14（API Level 34）
- **推荐版本**：Android 10 及以上（悬浮窗体验更佳）

> 注：Android 12 及以上版本对无障碍服务和悬浮窗权限有更严格的限制，需要用户手动在系统设置中授权。

## 需要的权限

| 权限 | 用途 | 是否必须 |
|------|------|----------|
| 无障碍服务 | 读取屏幕文本内容，识别支付页面和商家信息 | 必须 |
| 悬浮窗（SYSTEM_ALERT_WINDOW） | 显示风险提醒悬浮窗 | 必须 |
| 通知权限 | 发送风险告警通知 | 必须 |
| 网络权限（INTERNET） | 同步告警记录到家人端、更新品牌库 | 必须 |
| 开机自启（RECEIVE_BOOT_COMPLETED） | 手机重启后自动启动守护服务 | 推荐 |
| 振动权限（VIBRATE） | 高危告警时振动提醒 | 推荐 |

> 所有权限均会在首次启动时通过引导页逐一说明，用户可选择授权或拒绝。缺少核心权限将导致应用无法正常工作。

## 隐私说明

**我们极度重视用户隐私。** 本应用的设计原则是「**能在本机处理的，绝不传到服务器**」。

- **本机处理**：所有屏幕内容分析、商家识别、风险判断均在手机本地完成
- **不上传原始屏幕内容**：永远不会上传任何屏幕截图或原始页面文本
- **最小化数据**：仅上传必要的告警摘要（商家名称、金额、时间）用于家人通知
- **可随时撤销**：用户可在系统设置中随时撤销无障碍等权限，也可在应用内清除所有本地数据
- **无账号体系**：无需手机号、无需注册，通过设备匿名 ID 识别

详细隐私政策请参阅 [PRIVACY.md](./PRIVACY.md)。

### 模块职责说明

| 模块 | 职责 |
|------|------|
| `data` | 定义所有数据模型和枚举类，不包含业务逻辑 |
| `engine` | 核心风险判定逻辑，包括品牌库匹配、六锚点计算、投资规则等 |
| `service` | 长期运行的后台服务，包括无障碍监听和悬浮窗管理 |
| `ui` | 用户可见的界面，按功能分包 |
| `network` | 与后端 API 的交互，封装 OkHttp 请求 |
| `receiver` | 系统广播监听，目前主要用于开机自启 |
| `util` | 通用工具类，提供权限检测、文本提取、SP 存储等功能 |

## 已知限制

使用本应用前，请务必了解以下限制：

### 1. 无法保证 100% 识别准确率
- 不同支付 App 的页面结构差异很大，部分页面可能无法正确提取商家名称
- 商家名称的 OCR/文本提取可能存在误差，尤其是图片形式的商家名
- 山寨品牌的识别依赖品牌库的完善程度，无法覆盖所有风险商家
- **本应用仅作辅助提醒，不能替代用户自身的风险判断**

### 2. 悬浮窗不能完全阻止交易
- 悬浮窗仅起到提醒作用，用户仍可手动关闭后继续支付
- 部分全屏游戏或视频应用可能导致悬浮窗被遮挡
- 某些定制 ROM 可能限制悬浮窗的显示效果

### 3. 部分应用可能无法读取
- 对于使用了 Android 「安全窗口」（FLAG_SECURE）的应用，无障碍服务无法读取其内容
- 部分银行 App、支付 App 可能开启了安全窗口保护
- 微信、支付宝等主流应用的普通支付页面通常可以正常读取

### 4. 系统限制
- Android 12+ 对无障碍服务的后台运行有更严格的限制，可能导致服务被系统查杀
- 部分国产 ROM（如小米、华为、OPPO 等）的电池优化策略可能导致后台服务被清理
- 建议将本应用加入电池优化白名单并锁定后台

### 5. 家人通知依赖网络
- 家人通知功能需要设备联网才能正常工作
- 网络不佳时可能存在通知延迟或丢失
