# 隐私政策摘要

**最后更新日期：2024 年 1 月**

「公司X光守护」（以下简称「本应用」）深知隐私对您的重要性。我们致力于以最低的权限、最少的数据，为您提供最有效的守护服务。本摘要以简洁易懂的方式说明我们如何处理您的信息。

> 本文档为隐私政策摘要，完整版本请以应用内展示的隐私政策全文为准。

---

## 我们的隐私原则

1. **本机优先**：能在手机上处理的，绝不传到服务器
2. **最小必要**：只收集实现功能所必需的最少数据
3. **透明可控**：您随时可以查看、导出、删除您的数据
4. **不做画像**：不进行用户画像，不用于广告推荐
5. **安全加密**：传输和存储均采用加密保护

---

## 收集哪些数据

### 1. 设备标识符

| 数据项 | 用途 | 存储位置 | 是否可关闭 |
|--------|------|----------|------------|
| 设备匿名 ID | 标识设备、关联家人绑定 | 本机 + 服务器 | 否（功能必需） |

- 说明：我们不会收集您的手机号、IMEI、MAC 地址等个人身份信息
- 设备 ID 为应用安装时随机生成的字符串，与您的真实身份无关
- 卸载应用后该 ID 即失效

### 2. 提取的商家名称和金额

| 数据项 | 用途 | 存储位置 | 是否可关闭 |
|--------|------|----------|------------|
| 商家名称 | 风险识别与判定 | 仅本机内存（实时处理） | 否（功能必需） |
| 交易金额 | 风险等级计算 | 仅本机内存（实时处理） | 否（功能必需） |

- 说明：
  - 这些数据通过无障碍服务从当前屏幕文本中提取
  - **仅用于实时风险判断**，处理完成后不会保存在本机（除告警记录外）
  - **不上传原始屏幕内容**，仅在触发告警时上传商家名称和金额的摘要

### 3. 告警记录

| 数据项 | 用途 | 存储位置 | 是否可关闭 |
|--------|------|----------|------------|
| 告警时间 | 历史记录展示 | 本机 + （如绑定家人）服务器 | 是（可关闭家人同步） |
| 商家名称 | 历史记录展示 + 家人通知 | 本机 + （如绑定家人）服务器 | 是（可关闭家人同步） |
| 交易金额 | 历史记录展示 + 家人通知 | 本机 + （如绑定家人）服务器 | 是（可关闭家人同步） |
| 风险等级 | 历史记录展示 + 家人通知 | 本机 + （如绑定家人）服务器 | 是（可关闭家人同步） |
| 场景类型 | 历史记录统计 | 本机 + （如绑定家人）服务器 | 是（可关闭家人同步） |

- 说明：
  - 告警记录默认仅存储在本机
  - **仅当您绑定了家人并开启家人通知时**，告警记录才会同步到服务器
  - 您可以随时在设置中关闭家人通知，关闭后不再上传新的告警记录

### 4. 家人绑定信息

| 数据项 | 用途 | 存储位置 | 是否可关闭 |
|--------|------|----------|------------|
| 家人昵称 | 识别不同家人 | 本机 + 服务器 | 是（可解绑） |
| 绑定关系 | 关联告警通知推送 | 服务器 | 是（可解绑） |

- 说明：家人端的标识同样为匿名 ID，不涉及真实姓名、手机号等个人信息

## 不收集什么

**我们郑重承诺，以下信息我们绝对不会收集、上传或存储：**

### 1. 原始屏幕内容
- 不会截屏
- 不会上传任何页面的完整文本内容
- 不会记录您浏览了什么页面、和谁聊天

### 2. 聊天记录和通讯内容
- 不读取微信、QQ、短信等应用的聊天内容
- 不收集联系人、通讯录信息
- 不收集通话记录

### 3. 位置信息
- 不申请定位权限
- 不收集 GPS、基站、WiFi 等位置数据

### 4. 相册和文件
- 不读取您的相册
- 不访问您的文件存储
- 不收集照片、视频、文档等个人文件

### 5. 麦克风和摄像头
- 不申请录音权限
- 不申请相机权限
- 不会监听或拍摄您的周围环境

### 6. 生物识别信息
- 不收集指纹、人脸等生物特征数据

### 7. 健康数据
- 不读取健康类应用的数据

## 数据存储位置

### 本机存储（主要）

绝大多数数据存储在您的手机本地，包括：

- 应用设置和偏好配置
- 告警历史记录
- 品牌数据库（用于风险匹配）
- 家人绑定信息缓存

存储路径：
- 内部存储：`/data/data/com.companyxray.guardian/`
- 这些数据仅本应用可以访问（Android 沙箱机制）
- 卸载应用时会一并删除

### 服务器存储（仅当开启家人通知时）

当您绑定家人并开启家人通知功能时，以下数据会同步到服务器：

- 设备匿名 ID
- 家人绑定关系
- 告警记录摘要（时间、商家名称、金额、风险等级）

服务器数据的使用：
- 仅用于向家人端推送告警通知
- 不会用于任何商业用途
- 不会出售、出租或共享给第三方

服务器位置：中国境内

数据保留期限：告警记录保留 90 天，到期自动删除

## 数据安全

我们采取以下措施保护您的数据安全：

### 传输安全
- 所有网络请求均使用 HTTPS 加密传输
- 使用 TLS 1.2+ 协议
- 证书校验，防止中间人攻击

### 存储安全
- 本地数据存储在应用私有目录，其他应用无法访问
- 敏感配置使用 Android Keystore 加密存储
- 服务器数据使用加密数据库存储

### 访问控制
- 服务器数据仅授权运维人员访问，且有严格的审计日志
- 不支持远程查看用户的屏幕内容或详细使用记录

## 撤销授权与删除数据的方式

您对自己的数据拥有完全的控制权。

### 撤销权限

您可以随时在系统设置中撤销已授予的权限：

| 权限 | 撤销路径 | 影响 |
|------|----------|------|
| 无障碍服务 | 设置 → 无障碍 → 公司X光守护 → 关闭 | 核心功能失效，无法监测支付页面 |
| 悬浮窗 | 设置 → 应用管理 → 公司X光守护 → 显示在其他应用上层 → 关闭 | 无法显示悬浮窗提醒 |
| 通知 | 设置 → 应用管理 → 公司X光守护 → 通知 → 关闭 | 无法接收通知提醒 |
| 网络 | 设置 → 应用管理 → 公司X光守护 → 流量使用情况 → 关闭 | 家人通知、品牌库更新等功能失效 |

> 撤销权限后，应用不会再收集或处理相关数据。

### 在应用内管理数据

进入应用 → 设置 → 隐私与数据，您可以：

1. **查看告警历史**：浏览所有本地存储的告警记录
2. **删除单条记录**：左滑或长按删除某条告警记录
3. **清空所有告警记录**：一键删除全部本地告警历史
4. **关闭家人通知**：停止向家人推送告警，停止同步到服务器
5. **解绑家人**：解除与家人的绑定关系
6. **导出数据**：将本地数据导出为 JSON 文件
7. **清除所有数据**：重置应用，删除所有本地数据

### 卸载应用

卸载应用是最彻底的数据删除方式：

- 卸载后，所有本地数据将被永久删除
- 服务器上的绑定关系和告警记录将在 90 天后自动清理
- 如需立即删除服务器数据，请通过应用内反馈渠道联系我们

### 删除服务器数据

如果您希望立即删除服务器上的个人数据：

1. 进入应用 → 设置 → 隐私与数据 → 请求删除服务器数据
2. 提交申请后，我们将在 15 个工作日内完成删除
3. 删除完成后您会收到通知

> 注意：删除服务器数据将同时解除所有家人绑定关系。

## 权限说明

### 无障碍权限
用途：识别付款页面的商家名称和金额，进行风险核验
我们不读取：密码、验证码、聊天记录、通讯录等个人隐私信息

### 悬浮窗权限
用途：在检测到风险时，在当前页面弹出提醒
说明：提醒不会自动消失，防止误操作错过；您随时可以关闭

### 通知权限
用途：发送风险提醒通知和守护状态通知
说明：关闭通知权限后，只有打开应用才能看到提醒

### 网络权限
用途：调用后端 API 进行品牌核验和发送告警给家人
说明：只上传必要的商家名称和风险信息，不上传原始屏幕内容
